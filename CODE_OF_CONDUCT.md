# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, be welcoming, and assume good intent. Harassment and personal attacks are not accepted in issues, pull requests, reviews, or any other project space.

## Reporting

If you see or experience behavior that breaks this code of conduct, report it through GitHub:

- Use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature on the comment, issue, or pull request.
- Or contact the maintainer, [@shanto462](https://github.com/shanto462), through GitHub.

All reports will be reviewed and handled in confidence. The maintainer may remove comments, lock threads, or block users who break this code of conduct.
